# Sonidos de inicio

Coloca aqui el audio del ladrido que quieres reproducir al arrancar la app.

- Usa un archivo corto en formato WAV o MP3.
- Nombra el archivo `dog_bark.wav` para usar la configuracion por defecto.
- Si prefieres otro nombre o ruta, ajusta `startup_sound_path` en `config/settings.py`.
